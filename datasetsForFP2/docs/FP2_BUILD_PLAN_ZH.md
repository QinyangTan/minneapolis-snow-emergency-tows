# FP2 数据接入与构建方案

本资料包采集于 2026-11-10。它是可复用的研究输入，不是“经济条件直接导致拖车”的结论。优先使用 `prepared/` 的整理结果；原始下载和元数据留在 `raw/` 与 `catalog/`。

## 可以立即构建的部分

1. **原有九事件地图**：`prepared/baseline_9_events/` 保留项目当前口径：5,423 条记录、87 个社区，68 条未匹配记录保留在全市总量。另存十事件版本供参考，不能无标识混合。
2. **社区人口、贫困、租房和车辆拥有情况**：`prepared/neighborhood_context_starter.json` 可按 `neighborhood` 与原地图连接。数值含 MOE、可靠性、统计总体；86 个社区匹配成功，Humboldt Industrial Area 的 ACS 值为 null。
3. **收入和房价**：`prepared/acs_2022_hennepin_wide.json`、2023、2024 版本有 GEOID、估计值和误差范围。人均收入 B19301、家庭收入中位数 B19013、住宅价值中位数 B25077、租金 B25064。它们是 tract/block group 数据，尚未做社区空间分配。市政府社区导出提供收入区间分布，并不直接提供人均收入，不能伪装成同一种指标。
4. **住房与停车资源**：2022–2025 年评估记录包含社区、评估价值、住宅单元、车库车位；2021–2025 年成交记录有成交日期、价格、住宅类型和剔除标记。分析住宅时要先过滤用途，并区分一笔交易含多个地块、非正常市场交易和土地交易。
5. **天气**：`prepared/weather_msp_daily_2015_2026.json` 含每日降雪、积雪、降水及最高最低温度，保留 trace 和质量标记；缺失不是零。机场站仅为全市天气背景。

## 建议的首版三视图

- 地图：原始拖车数量／每千居民记录数切换。
- 社区散点图：先用可直接连接的贫困比例或收入区间指标；完成空间口径审核后再加入人均收入。房屋评估、成交价与 ACS 住宅价值是不同指标，分开标注。
- 社区详情：跨事件和 Day 1–3 分布；展示人口、租房、无车家庭、车库资源等背景。

保留选择的社区、事件、日期及分母；地图与图表联动。首版无需加载 1 GB 原始包，只应加载审定的轻量聚合 JSON。

## 下一步必须处理的连接

| 数据 | 连接方式 | 注意事项 |
|---|---|---|
| 市政府社区 ACS | 使用已保存名称对应表；再核验边界版本 | 名称一致不保证历史边界完全一致；统计期 2020–2024 |
| Census tract / block group | GEOID 连接 TIGER 边界，再与社区叠加 | 全县数据包括 Minneapolis 外地区；不可直接按行号或名称接合 |
| 人均收入 | 使用人口及收入总额进行有依据的空间分配 | 人口加权仍可能是近似；不能声称获得精确社区人均收入 |
| 收入、房价中位数 | 优先同地理单位使用，或以原始分布重估 | 不能平均 tract 中位数来得到社区中位数 |
| 评估／成交记录 | 社区字段或坐标、地块编号连接 | 坐标单位查看源元数据；土地价格≠房屋价格；车库车位有缺失／零值语义问题 |
| 历史交通流量 | LOCATION_ID 连流量历史与站点／路段 | 历史记录可能有今天已停用的站点；不能丢掉后当完整样本 |
| 路缘与道路 | 空间相交后计算区内长度 | 用合适的本地投影；不能将经纬度差直接当米；地图未必覆盖全部停车资源 |
| 公交 GTFS | stop 坐标空间连接；按 service_id 与日期确定服务 | 历史事件已有对应周档案；计划班次不是实际到站，也不是居民使用率 |
| 天气与拖车 | 本地日期／明确事件时间窗 | UTC 午夜日期字段可能只是日历日期，不能推断真实拖车时刻 |

## 仍然缺失、不能用代理数据替代的内容

**普通冬季实际拖车明细以及原因代码。** 本轮没有找到已验证、可下载且能覆盖正常状态和雪灾状态的完整官方明细。雪灾拖车图层只是其中一部分。

- 311 是投诉／服务请求，不是完成拖车。
- 911 是接警／调度记录，不是完成拖车；已保存类别计数与接口元数据。
- 严重事故数据只覆盖严重伤亡／死亡事故，不是全部事故，更不是全部事故拖车。
- 罚单 Tags 和拖车 Tows 是两种操作；不能直接把两类总量相除当成一辆车被拖走的概率。
- 当前公布的停车、路缘、租赁许可是当前快照，不能不加说明地回填到 2022 年。
- 选中的九／十次紧急状态不是全部事件日历，不能把“未出现在所选事件中”的所有日期标为正常日。

准备好的 `NORMAL_TOW_DATA_REQUEST_DRAFT.md` 可以用于提出公开数据申请；本次没有发送或提交。

## 历史扩充审核

已保存更早的雪灾拖车与罚单图层，但仅完成下载完整性审核，未将全部图层认定为有效、独立、完整的拖车事件。`catalog/snow_layer_audit.json` 提供每层记录数、Day 字段分布、日期字段范围和几何／日期重复检查。

Victory2 等不完整事件不能直接加入原有完整三日比较。Oliver 2021 等层中罚单与拖车数量相同或接近的情况要核对源描述、字段和定义；相同总数本身不能证明重复或错误。

## 冻结版本与可复现性

所有来源 URL、抓取时间、筛选条件、文件路径和 SHA-256 见 `catalog/datasets.json`。ArcGIS 字段类型、别名、更新时间、描述与使用条款保存在 `catalog/metadata/`。本资料包的“downloaded”只表示成功下载并通过格式／记录数等检查，**不表示该数据已经通过分析语义、历史覆盖或因果识别审核**。

ACS 的 2022、2023、2024 指五年估计期结束年份，三期窗口重叠，不能当作三个独立年度样本；美元量是各版本对应年的币值。抽样误差较大的社区应显示 MOE／可靠性，不应仅靠排序制造强结论。

建议最后的数据粒度为“社区 × 日期或事件阶段 × 环境状态 × 拖车原因”。事故分析优先考虑车辆流量，清雪分析优先考虑路边停车暴露；每千居民只能作为描述性规模校正，并非个体拖车风险。
