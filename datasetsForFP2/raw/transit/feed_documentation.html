Schedule and Realtime Data Feeds

General Transit Feed Specification (GTFS) data

These data include bus, light rail, and commuter rail service for the Minneapolis / St. Paul metropolitan area. This includes service operated by Metro Transit, the Metropolitan Council, Maple Grove Transit, Plymouth Metrolink, SouthWest Transit, the University of Minnesota, and the Metropolitan Airports Commission (MAC). The Minnesota Valley Transit Authority (MVTA) also provides service in the region.

Schedule and realtime data are provided in the General Transit Feed Specification (GTFS) format.

  • GTFS documentation
  • Documentation on Metro Transit's extensions to GTFS

Static schedule data

The current bus and light rail schedule is available at: https://svc.metrotransit.org/mtgtfs/gtfs.zip

GTFS-Flex - Metro Micro Service schedule: https://svc.metrotransit.org/mtgtfs/gtfs-flex.zip

The upcoming schedule is typically available Thursday afternoons, effective the following Saturday at: https://svc.metrotransit.org/mtgtfs/next/gtfs.zip

In general, schedule data are updated weekly, starting on Saturdays, and cover seven weeks. However, schedule data are subject to change at any time. We recommend checking for a new feed daily. It is always available at the above URL.

You can use the "Last-Modified" header to see whether there has been an update. "Last Modified" can be used with the "If-Modified-Since" request header to return a 304 http response if the file has not been changed.

GTFS-realtime data

Metro Transit's GTFS-realtime feeds are refreshed every 5 seconds.

  • TripUpdate feed: https://svc.metrotransit.org/mtgtfs/tripupdates.pb
  • VehiclePosition feed: https://svc.metrotransit.org/mtgtfs/vehiclepositions.pb
  • ServiceAlerts feed: https://svc.metrotransit.org/mtgtfs/alerts.pb

MVTA GTFS data

The Minnesota Valley Transit Authority (MVTA) also provides service in the region; their service data are available separately at https://srv.mvta.com/InfoPoint/GTFS-zip.ashx.

MVTA's GTFS-realtime feeds are also available.

  • TripUpdate feed: https:/srv.mvta.com/infoPoint/GTFS-realtime.ashx?&Type=TripUpdate
  • VehiclePosition feed: https://srv.mvta.com/infoPoint/GTFS-realtime.ashx?&Type=VehiclePosition
  • ServiceAlerts feed: https://srv.mvta.com/infoPoint/GTFS-realtime.ashx?&Type=Alert

Archive

Past weekly updated GTFS.zip static schedule files are available under /mtgtfs/archive/. The previous week's data file is added to the archive with each Saturday update in the format below replacing {yyyyMMdd} with the 8 digit date of a previous Saturday. (files begin at 20201128)

"https://svc.metrotransit.org/mtgtfs/archive/gtfs{yyyyMMdd}.zip".

Archive directory listing: https://svc.metrotransit.org/mtgtfs/archive/
